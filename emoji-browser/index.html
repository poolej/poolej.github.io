Favorites Sync

GitHub Pages is static, so favorites can’t auto-sync by themselves. Export a tiny backup file or paste a sync code on another machine.

Sync Help

Your favorites and recent emoji are normally saved in this browser only, using local browser storage for this site. That means they follow this browser profile on this machine, but they do not automatically appear in another browser or on another computer.

To move favorites to another machine, click Export JSON. Your browser will usually place the file in your Downloads folder unless you’ve chosen a different default download location. On the other machine, open this same emoji browser and click Import JSON, then select that exported file.

If you prefer not to manage a file, click Copy Sync Code to copy a small text backup to your clipboard. Send it to yourself in whatever private place you trust, then open the app elsewhere and use Paste Sync Code.

The export file only contains your favorites list and a timestamp. It does not include account credentials or anything from the rest of your computer.
